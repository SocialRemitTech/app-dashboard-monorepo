# @sr/dashboard (Phase 3)

React (web) dashboard suite — MLRO / NGO / B2B / Admin. Not built yet.
Consumes the SAME shared packages as the mobile app: `@sr/domain`, `@sr/api-contract`,
`@sr/config`, `@sr/design-tokens`. This is the "shared core, split surface" principle in code —
the web surface reuses the brain, only the presentation differs.
